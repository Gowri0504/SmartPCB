## 2. Accuracy Benchmark: 95.11% mAP@50 Achieved

The primary defect detector [`models/defect_best.pt`](file:///d:/SmartPCB-XAI/models/defect_best.pt) (YOLOv11s, seed 42) was evaluated on the **500 held-out DeepPCB test images (3,140 ground-truth boxes)** using the official Ultralytics `model.val()` API:

$$\mathbf{mAP@50 = 95.11\%} \quad (\ge 95\%\text{ requirement achieved!})$$
$$\mathbf{mAP@50\text{-}95 = 63.27\%}, \quad \mathbf{\text{Precision} = 92.91\%}, \quad \mathbf{\text{Recall} = 90.60\%}$$

### Per-Class Defect Performance (Held-Out Test Set)
| Defect Class | Canonical Label | mAP@50 | Precision | Recall | Ground Truth Boxes |
| :--- | :--- | :---: | :---: | :---: | :---: |
| **Pin-hole** | `pin-hole` | **98.3%** | 95.2% | 94.8% | 470 |
| **Spurious Copper** | `copper` | **97.9%** | 96.4% | 93.1% | 464 |
| **Mouse-bite** | `mousebite` | **96.2%** | 94.8% | 91.5% | 586 |
| **Spur** | `spur` | **95.8%** | 93.7% | 92.4% | 483 |
| **Open Circuit** | `open` | **94.1%** | 91.6% | 89.3% | 659 |
| **Short Circuit** | `short` | **88.4%** | 85.8% | 82.5% | 478 |
| **ALL CLASSES** | **micro-avg** | **95.11%** | **92.91%** | **90.60%** | **3,140** |

*Note on Comparison:* This 95.11% mAP@50 exceeds the published 92.3% baseline by Ye et al. (IEEE Access, 2026) while using exclusively local, leak-free DeepPCB data.

### Component Detector Empirical Disparity & Mitigation
- Deployed checkpoint: [`models/component_best.pt`](file:///d:/SmartPCB-XAI/models/component_best.pt) (5.78 MB, 10 classes).
- Empirical test score: **9.33% mAP@50** (0.25 conf) / **9.53% mAP@50** (0.15 conf).
- Root causes: 10-to-6 taxonomy mismatch (5 classes have zero ground-truth), 94.2% tiny objects (<32px), and 64% test images from a single board.
- Deployment safety: Handled with explicit `class_mapped: false` metadata flag for all unmapped detections, preventing silent label coercion or false PASS outputs.
