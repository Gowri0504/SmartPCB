2. HOW TO RUN THE PROJECT
--------------------------------------------------------------------------------
Open three separate terminal windows in D:\SmartPCB-XAI:

Terminal 1 — FastAPI AI Inference Service:
  cd D:\SmartPCB-XAI
  python -m uvicorn ai_service.main:app --host 127.0.0.1 --port 8000 --reload

Terminal 2 — Express Application Backend:
  cd D:\SmartPCB-XAI\backend
  npm start

Terminal 3 — React Industrial Dashboard:
  cd D:\SmartPCB-XAI\frontend
  npm run dev -- --host 127.0.0.1 --port 3000

Access the web interface at:
>>> http://localhost:3000 <<<

Run Automated Test Suite:
  python -m unittest discover -s tests -p "test_*.py"

Run Live End-to-End Test:
  python tests/test_e2e_live.py

3. WHAT, WHY, WHERE, HOW MATRIX
--------------------------------------------------------------------------------
Technology / Module | Why Used                       | Where Used             | How Implemented
--------------------|--------------------------------|------------------------|---------------------------------
YOLOv11s            | SOTA accuracy/latency tradeoff | ai/training/, models/  | Dual heads (components + defects)
Grad-CAM++          | Multi-instance visual XAI      | ai/xai/gradcam.py      | PyTorch backward hooks on bottleneck
CLAHE               | Trace contrast enhancement     | ai/inference/engine.py | OpenCV LAB L-channel equalization
Grid-Tiling (640px) | Avoid downsampling small parts | scripts/dataset/       | 128px overlap, box recalibration
Severity Formula    | IPC-A-610 defect grading       | ai/severity/           | Base_weight * Crit * (1 + 10*Area)
ReportLab & OpenPyXL| Formal compliance certificates | ai/reports/            | Generates PDF & multi-sheet Excel
FastAPI             | Async Python AI microservice   | ai_service/main.py     | Serves /inspect, /health, /reports
Express.js          | Web business logic & auth      | backend/server.js      | JWT, Multer upload, MongoDB CRUD
React 18 + Vite     | Industrial responsive UI       | frontend/src/          | Dark theme, Recharts, Canvas
Digital Twin        | Visual spatial board schematic | components/DigitalTwin | 2D SVG/Canvas interactive nodes
Continuous Learning | Human-in-the-loop retraining   | components/Feedback    | MongoDB feedback collection
